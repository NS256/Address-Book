# Address Book Java Project

This is a simple Java project scaffolded with a `src` directory and a `Main.java` entry point.

## How to Compile and Run

1. Open a terminal in the project root directory.
2. Compile:
   ```sh
   javac src/Main.java
   ```
3. Run:
   ```sh
   java -cp src Main
   ```

---

This project is ready for further development. Replace the `Main.java` file with your own code as needed.
